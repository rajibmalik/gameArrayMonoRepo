# Steam Gaming Dashboard Web Application

## Description 
This project is a gaming dashboard web application built using the MERN stack (MongoDB, Express, React, Node.js). The dashboard integrates with the Steam OpenID API to enable users to login and display data from game related APIs. This project was developed as part of my dissertation at the University of Glasgow, following agile methodology, testing and gathering of user feedback.

## Video demonstration
A video demonstration of the current state of the project is provided using the following link https://www.youtube.com/watch?v=V4ncqUXtHh4

## Tech Stack 
* Frontend: React, HTML5, CSS3, Chakra UI
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: Steam OpenID
* APIs Used: Steam API 

## Usage
This application can be easily accessed by using the following link: https://game-array-mono-repo-deployment.vercel.app/

The frontend is deployed using Vercel, and the backend is hosted on Render. As the application is hosted using a free tier, it may be slow to load at first, so please be patient.
